# ZAKS Drive visual brief

There is **no logo yet**. A placeholder mark would be worse than none, so the project uses a typographic header only. This brief is for a designer or the project owner.

## Name

"ZAKS Drive" with a space in prose; `zaks-drive` in technical identifiers. Tagline: *Open-Source Enterprise Content Gateway*.

## Typographic header (current)

Wordmark "ZAKS Drive" in a heavy sans-serif, tagline beneath in a regular weight. See `social-preview.svg`.

## Palette (proposal)

| Role | Hex | Use |
|---|---|---|
| Ink | `#0B1F33` | Background, text |
| Accent | `#2F9E8F` | Highlights, links between nodes |
| Paper | `#F4F7FA` | Text on dark, light backgrounds |
| Muted | `#8DA2B5` | Secondary text |

Avoid SAP blue/gold and Microsoft's four-colour mark: the project is independent and must not look affiliated.

## Logo requirements (when commissioned)

- Reads at 16 px and 512 px; works in one colour.
- No SAP, Microsoft or SharePoint logos, marks or lookalikes. No cloud-with-arrow clichés.
- Delivered as SVG, with a monochrome version.
- Needs trademark clearance together with the name before use.

## Social preview

1280 x 640 px, PNG or JPEG under 1 MB, key content inside a 40 px margin. Source: `social-preview.svg`; render with e.g. `rsvg-convert -w 1280 -h 640 social-preview.svg -o social-preview.png`. Uploading it to GitHub is an owner action (Settings, Social preview).
